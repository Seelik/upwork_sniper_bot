# Upwork Sniper Bot — Project Memory

## Назначение проекта
Телеграм-бот для ручного поиска и AI-фильтрации свежих вакансий с Upwork под стек Python/Backend/Scraping.

## Основные правила и архитектура
1. **Режим работы:** Только ручной запуск по запросу пользователя из Telegram (никаких фоновых авто-парсеров и бесконечных циклов).
2. **База данных:** SQLite (`jobs.db`) — используется для предотвращения повторной отправки одинаковых вакансий.
3. **Парсер:** Модуль сборщика RSS-лент Upwork.
4. **AI-фильтр:** Быстрый анализ описания вакансий через Groq API.
5. **Интерфейс:** `aiogram 3` (Telegram Bot API).
6. **Версионирование:** Git (фиксация рабочих изменений после каждого успешного шага).
